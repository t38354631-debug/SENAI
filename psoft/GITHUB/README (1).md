# Introdução ao GitHub

## O que é o GitHub?

O GitHub é uma plataforma online usada para armazenar, compartilhar e colaborar em projetos de programação utilizando o sistema de controle de versão Git.

## Principais Funções

- Armazenamento de códigos em repositórios
- Controle de versões e alterações
- Trabalho em equipe em projetos
- Compartilhamento de projetos open source
- Backup de arquivos e códigos

## Conceitos Importantes

### Repositório
Local onde os arquivos do projeto ficam armazenados.

### Commit
Registro das alterações feitas no projeto.

### Branch
Linha separada de desenvolvimento usada para testar mudanças.

### Pull Request
Solicitação para juntar alterações de uma branch ao projeto principal.

## Vantagens do GitHub

- Facilita o trabalho em equipe
- Organiza versões do projeto
- Permite colaboração mundial
- Gratuito para projetos públicos

## Conclusão

O GitHub é uma ferramenta essencial para desenvolvedores, permitindo organização, colaboração e segurança no desenvolvimento de projetos.
